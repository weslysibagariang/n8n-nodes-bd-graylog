# n8n-nodes-bd-graylog

This is an n8n community node. It lets you use Graylog in your n8n workflows by leveraging AWS SSM Parameter Store to get the Graylog credentials.

[n8n](https://n8n.io/) is a [fair-code licensed](https://docs.n8n.io/sustainable-use-license/) workflow automation platform.

## Installation

Follow the [installation guide](https://docs.n8n.io/integrations/community-nodes/installation/) in the n8n community nodes documentation.

## Operations

- Event Notifications
    - Get Event Notifications
- Search
    - Views Search
    - Search Aggregate

## Credentials

It doesn't need to set up the credentials to use the node instead it's just need the graylog instance region (EU, US, AP, etc)

## Compatibility

* Compatible with n8n@1.60.0 or later
* Doesn't support with n8n cloud
